# 💳 Customer Transaction Prediction

## 📌 Project Overview
This project uses Machine Learning to predict whether a customer will make a transaction in the future, irrespective of the transaction amount.

## 🎯 Problem Statement
To develop a predictive model that helps identify customers who are likely to make future transactions based on historical customer data.

## 📊 Dataset Information
- **Domain:** Banking
- **Dataset:** Customer Transaction Prediction
- **Features:** 200 anonymized features
- **ID Column:** `ID_code`
- **Target Variable:** `target`
- **Target Values:**
  - 0 – Customer will not make a transaction
  - 1 – Customer will make a transaction

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## ⚙️ Project Workflow
1. Data Loading and Understanding
2. Data Preprocessing
3. Feature Analysis
4. Train-Test Split
5. Machine Learning Model Building
6. Model Comparison
7. Model Evaluation
8. Final Model Selection

## 🤖 Machine Learning
Classification algorithms were implemented and evaluated to identify the best-performing predictive model.

## 💡 Business Objective
- Identify potential transacting customers.
- Understand customer transaction patterns.
- Support data-driven customer targeting.
- Help banking businesses improve customer engagement.

## 🏁 Conclusion
This project demonstrates the application of Machine Learning classification techniques to predict future customer transactions using anonymized data.
